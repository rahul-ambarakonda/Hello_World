# Hello World Application

This project is a simple "Hello World" web application.

## Setup

No special setup is required. Ensure you have Python installed on your system.

## Running the Server

To run the application server, navigate to the `hello_world_app` directory and execute the `server.py` script:

```bash
cd hello_world_app
python server.py
```

## Accessing the Application

Once the server is running, you can access the application by opening your web browser and navigating to:

[http://localhost:8000](http://localhost:8000)

## Stopping the Server

To stop the server, return to your terminal and press `Ctrl+C`. This will gracefully shut down the running server process.

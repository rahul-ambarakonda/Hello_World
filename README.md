# Hello_World

## How to Run the Application

To run the "Hello World!" application, follow these steps:

1.  **Navigate to the application directory**:
    ```bash
    cd hello_world_app
    ```

2.  **Run the server**:
    ```bash
    python server.py
    ```
    You should see output similar to `serving files from static at port 8000`.

3.  **Access the application in your web browser**:
    Open your web browser and go to `http://localhost:8000`. You should see a page displaying "Hello World!".
